# AGENTS.md — Chalkolate Architecture & Invariants

## Repository Layout

- `server/` + `api/` — Stateless Python 3.12+ FastAPI service (`uv`-managed, root `pyproject.toml` / `uv.lock`). `api/index.py` is the Vercel entrypoint (it adds `server/` to `sys.path` and exports `app`); keep it the only `.py` file in `api/`, because Vercel turns every `.py` file there into its own function. Application modules (flat imports) live in `server/`, tests in `server/tests/`.
  - `server/config.py`: Resolves `REPO_ROOT/.env` and `server/.env` independently of the launch working directory (`load_dotenv(..., override=False)`), validates `GEMINI_THINKING_LEVEL` (`minimal|low|medium|high`), numeric/speech/CORS settings, and redacts `gemini_api_key` and `elevenlabs_api_key` in `__repr__`. Defaults: `gemini_model="gemini-3.8-flash"`, `elevenlabs_model_id="eleven_v4_turbo"`, `analysis_timeout_seconds=12.0` (per attempt; the outer deadline is `attempts * timeout + 2s` retry delay), `speech_timeout_seconds=10.0`, `speech_rate_limit_per_minute=30`, `max_model_long_edge=1600`.
  - `server/schemas.py`: Strict Pydantic v2 contracts (`extra="forbid"`, `allow_inf_nan=False`) with field descriptions on all model-visible fields. Separates model-space `DetectedError` (`BoardAnalysisResult`, concise `board_summary` max 600 chars, `explanation` max 300 chars) from canonical source-space `SourceSpaceDetectedError` (`AnalysisResponse`). `AnalysisMetadata` accepts `request_id`, `previous_board_summary`, and `corners` (subject is auto-inferred from board content). `BoardDetectionResponse` models corner detection output; `SpeechRequest` validates plain-text TTS payloads (`text` 1..240 chars); `HealthResponse` reports `analysis_configured` and `speech_configured`.
  - `server/vision.py`: Safe Pillow decoding with pre-decode pixel cap (`ImagePixelLimitError`) and `exif_transpose`, explicit RGB/BGR/LAB conversions, strict TL/TR/BR/BL convex calibration validation without reordering, lightweight OpenCV automatic board corner detection (`detect_board_corners`, multi-threshold Canny + Otsu + Hough line intersections scored by aligned Sobel gradient support and border contrast, returning `detected=False` honestly when no reliable board exists), `getPerspectiveTransform`/`warpPerspective` using OpenCV pixel-center adjustment (`M_cv = T(-0.5) @ H_cont @ T(+0.5)`), fast subsampled contrast check + low-contrast L-channel CLAHE (`_auto_enhance` when LAB L std < `45.0`), JPEG encoding (`quality=90`, capped by `max_model_long_edge` without upscaling), and 4-corner inverse projection with outward rounding and clamping.
  - `server/analyzer.py`: Single-model async Gemini inference (`gemini-3.8-flash` default) via `client.aio.models.generate_content`, cached module-level `response_json_schema`, `ThinkingConfig` mapped from `settings.gemini_thinking_level`, `AutomaticFunctionCallingConfig(disable=True)`, `response_mime_type="application/json"`, bounded `max_output_tokens`, millisecond `HttpOptions(timeout=...)` with bounded 503-only retries (`attempts=2`), no `temperature`/`top_p`/`top_k`/penalties, explicit handling of blocks/truncation/malformed JSON/API errors, heuristic `confidence >= 0.85` filtering, and prompt rules enforcing one finding per distinct conceptual mistake across math, physics, engineering, chemistry, programming/code, and spelling plus natural TTS-friendly `spoken_alert` phrasing without LaTeX or `[...]` tags.
  - `server/speech.py`: ElevenLabs v4 Turbo (`eleven_v4_turbo`) HTTPS streaming client (`POST /v1/text-to-speech/{voice_id}/stream?output_format=mp3_44100_128`), `validate_voice_id`, `prepare_spoken_text` (strips control chars and square-bracket tags, normalizes math/physics shorthand, enforces `300`-char cap), `SlidingWindowRateLimiter`, typed auth/plan-tier/quota/rate-limit/timeout/unavailable exceptions (`SpeechPlanError` on `402 paid_plan_required` distinct from `SpeechQuotaError`), and `OpenedSpeechStream` cleanup without logging credentials or spoken text.
  - `server/main.py`: FastAPI lifespan managing single `genai.Client` (`aio.aclose()` + `close()`) and `httpx.AsyncClient` (`aclose()`), `RequestBodyLimitMiddleware` enforcing per-route body limits on `/api/analyze`, `/api/detect-board`, and `/api/speech` (`4096` bytes) for both `Content-Length` and streamed bodies, independent `ConcurrencyGate` instances for analysis and speech, `GET /api/health` (no upstream probes), `POST /api/detect-board` (works without API keys), `POST /api/speech` (rate-limited, concurrency-gated MP3 `StreamingResponse` with `Cache-Control: no-store`, `SPEECH_VOICE_PLAN_REQUIRED` mapping, and guaranteed gate release), `POST /api/analyze` offloading OpenCV/Pillow to `asyncio.to_thread`, and consistent `ErrorEnvelope` responses without logging secrets, image frames, or raw provider text.
- Repo root — Next.js 16 (App Router, client-only studio via `src/app/ClientApp.tsx`) + React 19 + TypeScript + Tailwind CSS v4 studio (Vitest for tests; `next.config.ts` rewrites `/api/*` to the local backend in dev only) (`package-lock.json`).
  - `src/api/schemas.ts` & `client.ts`: Zod runtime validation of `/api/health`, `/api/detect-board`, `/api/analyze`, and `ErrorEnvelope` payloads, plus streaming `requestSpeechStream` (`/api/speech`); typed `ApiClientError` with `Retry-After` extraction; relative `/api/*` URLs (Next.js rewrite to the local backend in dev; the root `vercel.json` rewrites `/api/*` to `api/index.py` on Vercel).
  - `src/lib/geometry.ts`: `object-contain` `ContainedImageRect` calculation, letterbox-excluding pointer mapping, strict TL/TR/BR/BL quad validation, normalized quad pixel masks, and clamped HTML pill positioning.
  - `src/lib/audioPlayer.ts`: User-gesture `unlockAudioPlayback`, low-latency progressive MP3 streaming player (`MediaSource` `SourceBuffer('audio/mpeg')` with automatic chunk-drained `Blob` fallback if MSE fails prior to start) with immediate `AbortSignal` teardown and `ObjectURL` cleanup.
  - `src/lib/frameCapture.ts`: Low-res (~320px long edge) grayscale sampling and upright JPEG capture (max 1600px, quality 0.86, no upscaling).
  - `src/lib/changeDetector.ts`: Tile-based (`16px`) illumination-compensated persistent change detection, motion fraction tracking, `activeChangedTiles` tracking, mask-aware tile calm checks (`isRegionCalm`), and bounding-box region classification (`'unchanged' | 'changed' | 'obscured'`, `REGION_CHANGED_FRACTION = 0.015`).
  - `src/lib/issueTracker.ts`: Persistent session tracker (`'open' | 'dismissed' | 'resolved'`) with intra-frame conceptual deduplication (`deduplicateFindings`, preferring smallest clear box on actual erroneous term while preserving distinct errors), four-tier cross-frame matching (Tier 1 normalized text, Tier 2 compact text, Tier 3 open-issue IoU + Levenshtein revision, Tier 4 overlapping conceptual equivalence across box granularity shifts) with box anchoring, occlusion-safe miss counting (`MISSES_TO_RESOLVE_CHANGED = 1`, `MISSES_TO_RESOLVE_UNCHANGED = 2`, `'obscured'` never increments `missCount` but flags `needsRecheck`), silent reopening, bounded history (`MAX_TRACKED_HISTORY = 120`), dismissals with Undo/Restore, and Mark Fixed verification.
  - `src/hooks/useMediaSource.ts`: Secure-context/capability checks, excludes placeholder (`deviceId === ''`) and `OBS Virtual Camera` entries while prioritizing integrated laptop webcams as default physical camera (`filterAndSortVideoDevices`), avoids restarting an already-live identical camera, releases prior MediaStream tracks before requesting new camera/screen streams (avoiding physical webcam `NotReadableError` locks and skipping `video.load()` during `srcObject` swaps), constraint/retry fallbacks, track `unmute` + `requestVideoFrameCallback` readiness handling, device disconnect handling, user-only video seek tracking, and object URL/track cleanup.
  - `src/hooks/useSpeechAlerts.ts`: Sequential non-overlapping alert queue preferring ElevenLabs v4 Turbo (`/api/speech` + `audioPlayer`) with client timeout (`12s`) when configured, permanent/timed failure cooldowns (`onProviderFallback` notification once per session), and automatic fallback to `window.speechSynthesis` (resuming paused Chrome queues with start/max watchdogs, only if playback did not already start), marking spoken only on `onStart`, duplicate suppression across frames, immediate cancellation on `cancelAll` / `syncActiveIssueIds` (when findings resolve or dismiss), and unmount cleanup.
  - `src/hooks/useBoardMonitor.ts`: Explicit `useReducer` state machine (`STOPPED | WATCHING | WRITING | ANALYZING`), Strict-Mode-safe `160ms` sampling loop running only while `monitoring && mediaReady && !calibrationEditing` (reusing sampled frame without duplicate readback on dispatch), early change clock tracking (`activeChangedTiles`) with tile-persistent dispatch (`CALM_MOVING_FRACTION = 0.30` or `MAX_CHANGE_WAIT_MS = 750`, `MIN_DISPATCH_GAP_MS = 250`), automatic quiet verification recheck (`VERIFY_RECHECK_DELAY_MS = 800`) for pending-miss / formerly-obscured open issues, single-flight + coalesced pending intent (`manual` > `auto`), ownership checks (`seq + monitoring + sourceGeneration + sessionGen + settingsSig`) that intentionally allow motion during inference, and synchronous ref-tracked failure backoff preserving open findings.
  - `src/components/`: `TopBar` (3-column grid centering uniform `h-8` Camera/Screen/Upload controls, minimal wordmark, gear Settings dialog), `Stage` (no idle Preview bubble or New Board button; subtle bottom-left `Analyzing…` text only while analyzing), `VideoTransport`, `DetectionOverlay` (`SVG viewBox="0 0 1000 1000"` + separate HTML pills, colors `#f43f5e` / `#f59e0b` / `#38bdf8`, without "Re-locating findings…" chrome), `CalibrationOverlay` (auto-detect + manual drag + Apply/Reset/Cancel), `FindingsPanel` (integrated collapsible right-edge / mobile bottom-edge chevron panel that naturally flex-resizes `Stage`, clean empty states without bottom informational note), `IssueCard` (omits confidence percentages cleanly), `Toasts`, and `MathCorrection` (`katex` with `trust: false`, guarded fallback).

## Key Engineering Invariants

1. **Monitoring Lifecycle & Default State**:
   - Monitoring is **stopped by default** on page load and never starts AI analysis or calls `getUserMedia` automatically.
   - Start/Stop controls AI monitoring independently of uploaded video playback; Stop aborts active HTTP checks and speech while preserving existing open findings for that board session.
   - Changing source, seeking/restarting an uploaded video, or committing calibration clears findings, summaries, baseline, and detector state.
2. **Coordinate Spaces**:
   - Canonical source coordinates are normalized `[0, 1000]` on the upright, unmirrored uploaded frame (`x_px = x * W / 1000`, `y_px = y * H / 1000`).
   - OpenCV pixel indices sit at centers `(i + 0.5, j + 0.5)`; `continuous_to_opencv_warp_matrix` converts continuous-bounds homographies via `T(-0.5) @ H_cont @ T(+0.5)` so identity calibration preserves every pixel and border identically.
   - Model `box_2d` coordinates always project all four corners through `inverse_homography`, validate `w > 1e-6` and finiteness, take source min/max, round outward, and clamp to `0..1000`. Perspective skew makes this source-space enclosure looser than the rectified box.
3. **Near-Real-Time Scheduling, Deduplication & Automatic Resolution**:
   - `changeDetector` tracks localized tile stability (`STILL_TICKS_FOR_PERSISTENCE = 2`) with global brightness offset compensation so writing triggers reanalysis (`<= 750ms` change wait cap) even while a presenter moves elsewhere in frame.
   - Motion during an active HTTP request does **not** invalidate its ownership; only Stop, source/session reset, or calibration change discards a late result.
   - Open findings remain visible across motion, transient API failures, and single unchanged/obscured misses; duplicate overlapping findings for the same conceptual mistake are consolidated to the smallest clear box; fixed or erased errors resolve automatically on `1` miss in a calm `'changed'` region or `2` misses in a calm `'unchanged'` region (driven by an automatic quiet verification recheck after `0.8s`), or immediately upon user-initiated Mark Fixed absence.
4. **Secrets & Privacy**:
   - `GEMINI_API_KEY` and `ELEVENLABS_API_KEY` live strictly on the server environment (Vercel env vars / local `.env`); never add `VITE_*` secret variables or expose raw credentials/frames/spoken text/model output in logs or HTTP error responses.
